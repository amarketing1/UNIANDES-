# Formatos y entregables

## Formatos recurrentes

### Digital
- 9:16 — historias / vertical.
- 4:5 — feed vertical; referencia recurrente 1080×1350.
- 1:1 — cuadrado.
- 1.91:1 — horizontal digital.

### Impresión
- A4 vertical.
- A4 horizontal.
- A3 vertical/horizontal según pieza.
- 14×10 cm vertical para adaptaciones puntuales.
- Roll-up: usar medidas exactas suministradas por el usuario; ejemplo trabajado 200 × 80 cm.

## Reglas de adaptación

- No estirar personajes ni deformar arquitectura.
- Reencuadrar priorizando el sujeto principal.
- Mantener espacio de seguridad para textos/logos.
- En ampliaciones a A3/A4, mejorar resolución y detalle sin inventar texturas artificiales.
- Si se solicita centrar la imagen, centrar el sujeto/elemento principal respetando márgenes visuales.
- Para impresión, evitar texto excesivamente pequeño y mantener iconos/logos definidos.

## Variantes recurrentes

Una misma pieza puede requerir:
- versión con textos,
- versión sin textos,
- solo fondo,
- solo personaje,
- solo elemento gráfico,
- PNG sin fondo,
- adaptación 9:16 / 4:5 / A4 / A3.

Cuando se solicite una variante, no rediseñar innecesariamente el resto.

## Calidad

- Alta resolución.
- Detalles limpios y definidos.
- Evitar halos, bordes dobles y artefactos de IA.
- Rostros y manos deben recibir revisión prioritaria.
- En fotografía de acción, usar desenfoque de movimiento/radial de manera controlada.
- En fondos, usar DOF realista en lugar de texturas artificiales para separar planos.
