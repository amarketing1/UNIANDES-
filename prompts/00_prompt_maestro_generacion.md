# Prompt maestro — generación visual UNIANDES

Usar esta plantilla como base y adaptarla al pedido concreto.

## Prompt base

Crear una pieza gráfica profesional para UNIANDES, con fotografía realista de alta calidad, composición limpia, jerarquía visual clara y lenguaje contemporáneo. Mantener reconocimiento institucional mediante una cromática coherente con el proyecto, priorizando azul oscuro, azul eléctrico, celeste y blanco cuando no exista otra temática específica. Integrar profundidad de campo realista, iluminación cuidada y separación clara entre primer plano, plano medio y fondo. Evitar texturas artificiales, ruido visual, piel plástica, manos deformes, letras accidentales y logotipos inventados.
